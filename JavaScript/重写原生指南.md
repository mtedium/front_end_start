# JavaScript 掌控感备忘录：从“神赐原子”到“野生重写”

这是一份用来打破黑箱、找回代码绝对控制权的思维地图。当对某个 API 感到不爽时，查阅此表，决定是去“强暴重写”它，还是“理智放过”它。

---

## 一、 计算机世界观：JS 的五个底层颗粒度

| 层级 | 颗粒度名称 | 代表选手 | 搞事指南 |
| :--- | :--- | :--- | :--- |
| **L1** | **业务应用层** | Vue, React, 高德地图 SDK | **大黑箱。** 天天调用的积木，不爽但没必要在这里死磕实现。 |
| **L2** | **高级封装层** | `Promise`, `fetch`, `setTimeout` | **半黑箱。** 包含异步或浏览器内核联动，不能全用纯逻辑重写。 |
| **L3** | **标准库 API 层** | `filter`, `sort`, `map`, `reduce` | **【黄金手写层】** 表面是 `[native code]`，脱了衣服全是 `for`/`while` 循环。**最值得去扒底裤。** |
| **L4** | **数组原子操作层** | `this[index] = val`, `delete` | **【野生基础层】** 知道原理即可，能用对象字面量 `{}` 完美模拟。 |
| **L5** | **绝对原子层** | `for`, `if`, `===`, `+`, `{}`, `return` | **【世界的尽头】** V8 引擎硬编码，无法重写，是一切的基石。 |

---

## 二、 终极判定法则：这个 API 能否被纯 JS 重写？

> **黄金提问法：**
> 如果把这段代码放进一个**没有外设、没有网络、只有 CPU 和内存**的“纯黑箱算力机”里，它还能跑吗？
> - **能跑** $\rightarrow$ 100% 可以用纯 JS 重写（哪怕控制台打印出 `[native code]`，也只是官方用 C++ 作弊优化了性能，逻辑依然是 `for` 循环）。
> - **不能跑** $\rightarrow$ 属于“神赐超能力”，必须依赖网卡、显卡、定时器芯片或操作系统，绝对无法凭空重写。

---

## 三、 绝对【无法重写】的死亡名单（黑箱超能力）

当你遇到以下目录的方法，请保持敬畏，它们是物理层面的原子，JS 语言没有语法能触碰它们：

### 1. 异步与时间驱动（依赖硬件定时器芯片/事件循环）
* `setTimeout` / `setInterval`（JS 无法凭空让代码“等一秒”，除非锁死 CPU）
* `requestAnimationFrame`（必须配合显示器的刷新率，由浏览器内核 C++ 控制）

### 2. 网络与外部通信（依赖物理网卡/硬件模块）
* `fetch` / `XMLHttpRequest`（发送网络请求，JS 伸不进网卡里）
* `WebSocket`（长连接通信）
* `navigator.geolocation`（获取 GPS 地理位置，调用硬件定位）
* `WebBluetooth` / `WebUSB`（控制外部蓝牙或物理外设）

### 3. 浏览器外壳控制与多线程（依赖运行时环境）
* `window.open()` / `window.close()`（操控浏览器标签页）
* `Worker`（开辟新的物理线程，JS 语言本身是单线程的）
* `history.back()` / `history.forward()`（操控浏览器前进后退历史）

### 4. 磁盘读写与本地存储（依赖操作系统文件系统）
* `localStorage` / `sessionStorage` / `IndexedDB`（底层由 C++ 写入磁盘）
* `FileReader` / `File` / `Blob`（读取用户选中的本地文件沙盒）

### 5. 声音、视频与图形硬件加速（依赖声卡/显卡 GPU）
* `HTMLMediaElement.play()`（驱动声卡发声）
* `CanvasRenderingContext2D` / `WebGLRenderingContext`（如 `ctx.drawImage`，直接扔给 GPU 渲染像素）

---

## 四、 绝对【可以重写】的通关名单（野生键盘侠）

遇到以下内容，只要你手痒，随时可以用最基础的 `for`、`if`、`{}` 把它砸得稀烂：

* **所有的标准数组方法**：`filter`、`map`、`reduce`、`every`、`some`、`flat`（全部可以转化成纯 `for` 循环）。
* **高阶算法方法**：`sort`（本质是快排/Timsort算法逻辑）。
* **工具类函数**：`防抖 (debounce)`、`节流 (throttle)`、`深拷贝 (deepClone)`。
* **高阶对象操作**：`Object.keys()`、`Object.values()`、`Object.assign()`。
* **控制流核心**：`Promise` 状态机（除了异步微任务调度需要通过 `queueMicrotask` 偷浏览器能力，其状态翻转和 `then` 链条完全可以手写）。
