# 异步编程完整指南

## 从实际问题出发

### 场景一：同步代码的困扰

想象一个电商网站的下单流程：

```js
// 同步写法
let user = getUser();           // 查询用户信息，假设耗时 100ms
let products = getProducts();   // 查询商品列表，假设耗时 200ms
let order = createOrder();      // 创建订单，假设耗时 150ms

console.log("下单成功");
```

**问题**：这段代码会阻塞浏览器 450ms，用户界面会卡住不动。

### 场景二：现实中的异步需求

```
用户点击"查询订单"
  ↓
发起网络请求（假设 2 秒才能返回）
  ↓
用户还能滚动页面、点击其他按钮吗？
```

**如果用同步**：界面卡死 2 秒，用户以为网页坏了。

**如果用异步**：界面正常响应，请求完成后通知你。

---

## 什么是同步和异步？

### 同步 (Synchronous)

```js
console.log("第一步");
console.log("第二步");
console.log("第三步");
```

输出：`第一步` → `第二步` → `第三步`

**特点**：代码按顺序执行，每一行必须等上一行执行完。

### 异步 (Asynchronous)

```js
console.log("第一步");

setTimeout(() => {
  console.log("第三步（异步任务）");
}, 1000);

console.log("第二步");
```

输出：`第一步` → `第二步` → `第三步（异步任务）`

**特点**：发起异步任务后，不等待结果，继续执行后面的代码。

---

## 为什么需要异步？

### 典型场景

| 场景 | 同步写法的问题 | 异步的优势 |
|------|---------------|-----------|
| 网络请求 | 页面卡死 | 界面正常响应 |
| 读取大文件 | 程序无响应 | 后台处理 |
| 计时器 | 阻塞后续代码 | 不耽误执行 |
| 数据库查询 | 长时间等待 | 先做其他事 |

**核心目标**：不阻塞主线程，让程序能够"同时"做多件事。

## 回调函数：异步的第一种解决方案

### 什么是回调？

**回调**：把一个函数当作参数传进去，等异步完成后调用。

```js
// 模拟：读取用户信息
function getUser(callback) {
  setTimeout(() => {
    callback({ name: "张三", age: 25 });
  }, 1000);
}

// 使用回调
getUser((user) => {
  console.log("获取到用户：" + user.name);
});

console.log("这行代码会先执行");
```

输出：
```
这行代码会先执行
（1秒后）获取到用户：张三
```

### 多个异步任务串联

```js
// 模拟：依次查询数据
function queryUser(userId, callback) {
  setTimeout(() => {
    callback({ id: userId, name: "张三" });
  }, 500);
}

function queryOrders(userId, callback) {
  setTimeout(() => {
    callback([{ id: 1, product: "手机" }, { id: 2, product: "电脑" }]);
  }, 500);
}

function queryRecommendations(userId, callback) {
  setTimeout(() => {
    callback([{ id: 1, name: "推荐商品1" }]);
  }, 500);
}

// 串联：先查用户，再查订单，再查推荐
queryUser(1, (user) => {
  console.log("用户：" + user.name);
  queryOrders(user.id, (orders) => {
    console.log("订单数量：" + orders.length);
    queryRecommendations(user.id, (recommendations) => {
      console.log("推荐数量：" + recommendations.length);
    });
  });
});
```

## 回调地狱

当异步任务嵌套层数增多，代码会变成：

```js
// 实际开发中常见的场景：登录 → 获取权限 → 获取菜单 → 获取数据
login(userName, (token) => {
  getPermissions(token, (permissions) => {
    getMenu(permissions, (menu) => {
      getData(menu, (data) => {
        render(data);
      });
    });
  });
});
```

**问题**：

1. **难以阅读**：嵌套层数多，逻辑不清晰
2. **难以维护**：修改内层代码，可能影响外层
3. **难以调试**：错误难以定位
4. **难以复用**：每个流程都要重新写一遍

这就是经典的 **"回调地狱"（Callback Hell）** 问题。

## Promise 登场

### Promise 是什么？

Promise 是一个承诺，表示一个异步操作**最终会完成**。

**三种状态**：
- `pending` - 等待中（初始状态）
- `fulfilled` - 成功了（已完成）
- `rejected` - 失败了（已拒绝）

**特点**：状态一旦改变，就不会再变。

### 基本用法

```js
// 创建 Promise
function getUser() {
  return new Promise((resolve, reject) => {
    setTimeout(() => {
      resolve({ name: "张三", age: 25 });
    }, 1000);
  });
}

// 使用 .then() 处理成功，.catch() 处理失败
getUser()
  .then((user) => {
    console.log("用户：" + user.name);
  })
  .catch((error) => {
    console.log("错误：" + error);
  });
```

### 解决回调地狱

```js
// 用 Promise 改写之前的例子
function queryUser(userId) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve({ id: userId, name: "张三" });
    }, 500);
  });
}

function queryOrders(userId) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve([{ id: 1, product: "手机" }]);
    }, 500);
  });
}

function queryRecommendations(userId) {
  return new Promise((resolve) => {
    setTimeout(() => {
      resolve([{ id: 1, name: "推荐商品1" }]);
    }, 500);
  });
}

// 链式调用，层级扁平化
queryUser(1)
  .then((user) => {
    console.log("用户：" + user.name);
    return queryOrders(user.id);
  })
  .then((orders) => {
    console.log("订单：" + orders.length);
    return queryRecommendations(1);
  })
  .then((recommendations) => {
    console.log("推荐：" + recommendations.length);
  });
```

**对比回调地狱**：同样的逻辑，Promise 用链式调用让代码清晰多了。

### Promise 常用方法

```js
// Promise.all - 等待所有 Promise 完成
Promise.all([
  queryUser(1),
  queryOrders(1),
  queryRecommendations(1)
]).then(([user, orders, recommendations]) => {
  console.log(user, orders, recommendations);
});

// Promise.race - 任意一个先完成
Promise.race([
  queryUser(1),
  new Promise((_, reject) => setTimeout(() => reject("超时"), 3000))
]).then((result) => {
  console.log(result);
});

// Promise.allSettled - 等待所有完成（无论成功或失败）
Promise.allSettled([
  queryUser(1),
  Promise.reject("失败了")
]).then((results) => {
  results.forEach((result) => {
    if (result.status === "fulfilled") {
      console.log("成功：" + result.value);
    } else {
      console.log("失败：" + result.reason);
    }
  });
});
```

## async/await：让异步像同步

### async/await 是什么？

async/await 是 Promise 的**语法糖**，让你写异步代码像写同步代码一样。

### 基本用法

```js
// async 函数自动返回 Promise
async function getUser() {
  return { name: "张三", age: 25 };
}

// await 等待 Promise 完成（只能在 async 函数中使用）
async function main() {
  const user = await getUser();
  console.log(user.name);
}

main();
```

### 用 async/await 改写之前的例子

```js
async function main() {
  const user = await queryUser(1);
  console.log("用户：" + user.name);

  const orders = await queryOrders(user.id);
  console.log("订单：" + orders.length);

  const recommendations = await queryRecommendations(user.id);
  console.log("推荐：" + recommendations.length);
}

main();
```

**优势**：代码看起来像同步执行，逻辑清晰。

### 错误处理

```js
async function main() {
  try {
    const user = await queryUser(1);
    const orders = await queryOrders(user.id);
    console.log(orders);
  } catch (error) {
    console.log("出错了：" + error);
  }
}

main();
```

### 多个异步任务并行

```js
// 串行：一个个等待，总耗时 1500ms
async function serial() {
  const start = Date.now();
  const user = await queryUser(1);    // 500ms
  const orders = await queryOrders(1); // 500ms
  const rec = await queryRecommendations(1); // 500ms
  console.log("串行耗时：" + (Date.now() - start));
}

// 并行：同时发起，总耗时 500ms
async function parallel() {
  const start = Date.now();
  const promises = [
    queryUser(1),
    queryOrders(1),
    queryRecommendations(1)
  ];
  const [user, orders, rec] = await Promise.all(promises);
  console.log("并行耗时：" + (Date.now() - start));
}
```

## 手写实现：从零理解 Promise

### 最简单的 Promise

```js
// 简化版 Promise
class MyPromise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;

    const resolve = (value) => {
      if (this.state === "pending") {
        this.state = "fulfilled";
        this.value = value;
      }
    };

    const reject = (reason) => {
      if (this.state === "pending") {
        this.state = "rejected";
        this.value = reason;
      }
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  then(onFulfilled, onRejected) {
    if (this.state === "fulfilled") {
      onFulfilled(this.value);
    }
    if (this.state === "rejected") {
      onRejected(this.value);
    }
  }
}

// 测试
new MyPromise((resolve, reject) => {
  setTimeout(() => resolve("成功"), 1000);
}).then((value) => {
  console.log(value); // 1秒后输出：成功
});
```

### 支持异步的 Promise

```js
class MyPromise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;
    this.onFulfilledCallbacks = [];
    this.onRejectedCallbacks = [];

    const resolve = (value) => {
      if (this.state === "pending") {
        this.state = "fulfilled";
        this.value = value;
        // 异步完成后，执行所有注册的回调
        this.onFulfilledCallbacks.forEach(fn => fn(value));
      }
    };

    const reject = (reason) => {
      if (this.state === "pending") {
        this.state = "rejected";
        this.value = reason;
        this.onRejectedCallbacks.forEach(fn => fn(reason));
      }
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  then(onFulfilled, onRejected) {
    if (this.state === "fulfilled") {
      onFulfilled(this.value);
    } else if (this.state === "pending") {
      // 如果还是 pending，把回调存起来
      this.onFulfilledCallbacks.push(onFulfilled);
      this.onRejectedCallbacks.push(onRejected);
    }
  }
}

// 测试
new MyPromise((resolve, reject) => {
  setTimeout(() => resolve("异步成功"), 1000);
}).then((value) => {
  console.log(value); // 1秒后输出：异步成功
});
```

### 支持链式调用的 Promise

```js
class MyPromise {
  constructor(executor) {
    this.state = "pending";
    this.value = undefined;
    this.onFulfilledCallbacks = [];
    this.onRejectedCallbacks = [];

    const resolve = (value) => {
      if (this.state === "pending") {
        this.state = "fulfilled";
        this.value = value;
        this.onFulfilledCallbacks.forEach(fn => fn(value));
      }
    };

    const reject = (reason) => {
      if (this.state === "pending") {
        this.state = "rejected";
        this.value = reason;
        this.onRejectedCallbacks.forEach(fn => fn(reason));
      }
    };

    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }

  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => {
      const handleFulfilled = (value) => {
        try {
          const result = onFulfilled(value);
          resolve(result);
        } catch (error) {
          reject(error);
        }
      };

      const handleRejected = (reason) => {
        try {
          const result = onRejected(reason);
          resolve(result);
        } catch (error) {
          reject(error);
        }
      };

      if (this.state === "fulfilled") {
        handleFulfilled(this.value);
      } else if (this.state === "rejected") {
        handleRejected(this.value);
      } else if (this.state === "pending") {
        this.onFulfilledCallbacks.push(handleFulfilled);
        this.onRejectedCallbacks.push(handleRejected);
      }
    });
  }

  catch(onRejected) {
    return this.then(null, onRejected);
  }
}

// 测试链式调用
new MyPromise((resolve) => {
  setTimeout(() => resolve(1), 500);
})
  .then((x) => x + 1)
  .then((x) => x + 1)
  .then((x) => {
    console.log(x); // 3
  });
```

## 总结

| 阶段 | 技术 | 问题 |
|------|------|------|
| 同步时代 | 阻塞等待 | 界面卡死，效率低 |
| 异步时代 | 回调函数 | 回调地狱，难以维护 |
| Promise 时代 | Promise | 链式调用，清晰优雅 |
| async/await 时代 | async/await | 语法糖，写法像同步 |

**核心理解**：

1. **为什么需要异步** - 不阻塞主线程，提高用户体验
2. **回调的问题** - 嵌套层级深，形成回调地狱
3. **Promise 的价值** - 链式调用，让异步代码可读性提高
4. **async/await** - Promise 的语法糖，写法更自然

**本质**：都是为**解决异步编程问题**而诞生的技术方案。
